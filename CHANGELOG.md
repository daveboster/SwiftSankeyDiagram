# Changelog

All notable changes to `SwiftSankeyDiagram` are documented here.

This project uses semantic versioning. While the package is below 1.0, minor
releases may include source-breaking API changes as the public diagram surface
stabilizes. Patch releases should remain source-compatible within the same
minor version.

## 0.1.0 - 2026-05-24

- Initial public Swift package release.
- Added generic SwiftUI Sankey node, link, style, layout, and rendering APIs.
- Added a cashflow playground example that maps app-owned data into the generic
  Sankey diagram model.
- Added Swift Testing coverage for basic layout and ribbon edge alignment.
- Published under the MIT License.
